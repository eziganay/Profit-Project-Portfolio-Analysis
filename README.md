# Company-Profit-Project-Portfolio-Analysis
## Project Overview
This project is a data analysis aiming to improve future company profit. Using financial performance data, analysis is performed to discover possible causes and resolutions regarding decreasing company profit through data gathering, cleaning, data illustration and reveals potentials.
## ⚠️ Problem Statement
The company is facing a dwindling company profit.. This analysis diagnoses where the culprits are coming from, whether these are from decreasing company revenue or increasing company expenses, and drilling their respective data.
## 📊 Datasets Summary
Nodes: Revenue and Expense Datasets
Attributes:
  Revenue:  Log_Date, Revenue_ID, Stream_Source, Gross_Amount, Reporting_Region
  Expenses: Date, Expense_ID, Category, Amount, Vendor, Notes
